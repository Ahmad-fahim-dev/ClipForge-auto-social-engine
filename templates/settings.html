    Auto-generate optimized titles, hooks, captions and hashtags when clips are created

  • Whisper Mode

    Transcription engine: auto (API then local), API upload, or local Whisper

  • Whisper Model

    Local model size (tiny → large-v3). API mode maps tiny/base/… to whisper-1
